## 出题方法（可复用）

- 四份课程 md 共约 382KB，直接读会爆上下文。改用 4 个并行子代理各啃一份，要求只返回「能直接改写成选项的硬事实 + 章节出处 + 易混点」，共抽出约 180 条。
- 已知的材料覆盖盲区（后续如要补题需注意）：MCP 配置机制、知识库 Schema/结构化字段/标签的产品化细节、引用溯源开关，课程材料本身没展开，只能从方案画布与六项确认里侧面出题。
- 校验用 Python 正则核对：题量、每选项数（单 4 / 多 5）、速查表与逐题解析答案一致、模块与难度计数自洽。**速查表是双栏排版，正则要同时取两列**，否则只匹配到左半边。
